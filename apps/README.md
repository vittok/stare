# S.T.A.R.E Standalone Portal

This folder contains the first standalone portal scaffold for S.T.A.R.E.

- `web/` is the Next.js frontend for Google sign-in, personalization, and the future dashboard.
- `api/` is the FastAPI service for database-backed report and preference endpoints.

The existing GitHub Pages app remains the public demo/fallback while this portal is built.

## Current Status

- Supabase schema has been applied with `supabase/migrations/001_initial_portal_schema.sql`.
- Existing report artifacts have been imported into Supabase/Postgres.
- `stock_recommendations` is populated from the shared `src/stare_signals.py` logic.
- FastAPI has a database-backed latest-report endpoint.
- Next.js has a first Google sign-in shell and Supabase callback route.

## Local Frontend

```bash
cd apps/web
npm install
npm run dev
```

The frontend expects these environment variables:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
- `NEXT_PUBLIC_APP_URL`
- `FASTAPI_URL`

## Local API

```bash
cd apps/api
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

The API expects:

- `DATABASE_URL`

Use the Supabase Session Pooler URL for `DATABASE_URL` when the direct database host is not reachable over IPv6. Keep it in local `.env` or deployment secrets only.

For local preference testing before full JWT validation is added, send an `x-user-id` header with a Supabase user UUID.

## Import Current Reports

From the repository root:

```bash
PYTHONPATH=.python_deps:src python src/export_reports_to_postgres.py --run-label "portal seed with shared recommendations"
```

This imports:

- one `update_runs` row
- sector and region snapshots
- stock snapshots
- matching stock recommendation rows generated by the shared signal module

## API Endpoints

- `GET /health`
- `GET /api/latest-report`
- `GET /api/me/preferences`
- `PUT /api/me/preferences`

Preference endpoints currently use an `x-user-id` header as a temporary development bridge until full Supabase JWT validation is wired into FastAPI.

See `../PORTAL_DEPLOYMENT.md` for production domain, OAuth callback, Session Pooler, and secret-rotation notes.

## Render UAT

The repository includes `../render.yaml` for Render Blueprint deployment:

- `stare-api` runs FastAPI from `apps/api`.
- `stare-portal` runs Next.js from `apps/web`.

Set these environment variables in Render:

- `stare-api`: `DATABASE_URL`, `CORS_ORIGINS`
- `stare-portal`: `FASTAPI_URL`, `NEXT_PUBLIC_APP_URL`

`NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` are included in the blueprint because they are browser-safe project configuration.
